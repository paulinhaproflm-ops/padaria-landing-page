# Landing Page – Padaria

Projeto acadêmico de landing page desenvolvido para uma padaria real.

## Tecnologias
- HTML, CSS e JavaScript
- Supabase (banco de dados)
- GitHub Pages (publicação)

## Estrutura
```
├── index.html      → estrutura da página
├── css/style.css   → estilos
├── js/script.js    → interatividade
├── img/            → imagens
└── docs/           → planejamento (briefing, escopo)
```
